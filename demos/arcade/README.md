# Faith's arcade demos

Public playable review collection: https://jhm-hub.github.io/scam-wheel/demos/arcade/

Dice Boost and Russian Roulette use Landaire-derived spin and landing logic, Faith's pink/lilac palette, bundled Nunito and procedural pixel art. The self-contained index.html includes the editable JavaScript and all runtime assets. No account is needed.

Use Spin for random landings or Play showcase for a clearly labelled scripted round. Amounts are editable; two opening spins precede the scam by default. Open clean view connects a transparent companion tab within the same browser/profile. It is not a cross-device or Twitch integration.

Concept references were reviewed from the user-supplied Lexiful recording with the user's reported permission. No footage, logos or character sprites are redistributed.

These are separate demos; the production wheel is unchanged. The deployment build copies this directory to dist/demos/arcade.
