# Saved versions, one OBS source

Settings are saved in this browser on this computer. Use the same browser/profile each time; this is not an account or cloud backup.

- **Save changes** updates the selected version.
- **Save as new version** keeps another setup, without creating another OBS source.
- Choose **Saved version** to return to a setup you saved before.
- Finish the viewer before applying another version to the live game.
- Keep the controls and complete pairing links private.

Open [Scam Wheel settings](https://jhm-hub.github.io/scam-wheel/) and choose **Settings**. Enter a version name, edit amounts, mode names, pool weights, colors or sound, then save. Saving updates practice; it does not interrupt OBS.

Open [private live controls](https://jhm-hub.github.io/scam-wheel/browser.html). Under **Prizes & game modes**, choose **Saved version**, then **Apply saved version & start fresh** between viewers. Keep the same OBS URL and source. The viewer rejects settings changes during an unfinished round.

**Put the wheel on stream** shows the permanent OBS link. Refresh the existing controls and source once between viewers to load the update. Retain 800 x 800 and disable shutdown/refresh on scene changes.

Existing prices are retained as **My saved settings**. Export settings from the editor for a portable backup. These instructions cover the direct browser source; the separate StreamElements installer remains available.
